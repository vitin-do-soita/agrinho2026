# 🌾 Projeto Agro Forte - Edição Agrinho 2026

Este repositório contém a aplicação web desenvolvida para o **Programa Agrinho**, com o objetivo de conscientizar e engajar a comunidade escolar sobre a importância da sustentabilidade, inovação e tecnologia no campo.

---

## 🎯 Objetivo do Tema Agrinho

O tema deste projeto busca desmistificar a agricultura moderna, apresentando o **Agro Forte** como uma força que une alta produtividade alimentar e preservação ambiental. A aplicação foi desenhada para mostrar de forma clara, interativa e acessível:
* Como a tecnologia de precisão reduz o desperdício de recursos naturais (como água e insumos).
* O papel fundamental do produtor rural na conservação das florestas e nascentes brasileiras.
* Pequenas ações práticas que alunos e a comunidade urbana podem adotar para apoiar o consumo consciente e local.

---

## 🛠️ Lista de Tecnologias Utilizadas

A página foi construída com foco em desempenho, acessibilidade e padrões modernos da web (sem dependências externas):

* **HTML5 Semântico:** Uso de tags estruturais para melhor leitura de tela e o elemento nativo `<dialog>` para criação de pop-ups leves e seguros.
* **CSS3 Customizado:** Utilização de Variáveis CSS para gerenciamento do Modo Escuro, design fluido com Flexbox/Grid e animações nativas.
* **JavaScript (Vanilla ES6):** Lógica para manipulação do DOM, controle de tamanho de fontes para acessibilidade, saudação baseada no horário real e armazenamento de preferências no `localStorage`.

---

## 🚀 Instruções de Uso

Para visualizar ou testar o projeto em sua máquina:

1. **Baixar o Código:** Faça o download dos arquivos `index.html`, `style.css` e `script.js` e coloque-os na mesma pasta.
2. **Executar:** Dê um duplo clique no arquivo `index.html` para abri-lo diretamente em qualquer navegador web atual (Chrome, Edge, Firefox, Safari).
3. **Interação:**
   * Alterne entre os modos claro e escuro clicando no ícone de lua/sol (`🌓`).
   * Ajuste o tamanho do texto para melhor leitura usando os botões `A+` e `A-`.
   * Clique nos cards informativos das seções **"O Agro em Números"** e **"Como Ajudar"** para abrir as janelas pop-up com os textos explicativos detalhados.
   * Para fechar qualquer pop-up, clique no botão `X`, aperte a tecla `Esc` ou simplesmente clique na área escura fora da janela.
